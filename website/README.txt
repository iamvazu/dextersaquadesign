DEXTER'S AQUA DESIGNS — scroll-world website
============================================

WHAT'S HERE
  index.html        the website (built on github.com/oso95/scroll-world)
  scrub-engine.js   scroll-world's scroll-scrub engine (unchanged)
  aqua.js           the living water layer, specimen windows, sound, contact form
  film-kit.html     the Gemini/Veo prompts + frame grabber (open it in Chrome)
  assets/img/       logo and specimen photos cropped from your flyer
  assets/vid/       put the Gemini clips here

ADDING THE FILM
  Save each clip into assets/vid with these exact names:
    01-arrive.mp4  02-aquarium.mp4  03-biotope.mp4  04-paludarium.mp4
    05-terrarium.mp4  06-waterfall.mp4  07-pond.mp4  08-pool.mp4
  Optional phone versions: same names ending in -m.mp4 (e.g. 01-arrive-m.mp4)
  Any scene without a clip keeps its specimen window, so you can add them one at a time.

PREVIEWING
  Double-clicking index.html works, but browsers block video loading from local files,
  so the film only plays when the site is served. Easiest: upload the folder to Netlify
  Drop (app.netlify.com/drop), Vercel, or GitHub Pages. Or ask Claude to optimise and
  test the clips for you.
